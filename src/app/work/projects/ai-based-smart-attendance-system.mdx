## Overview

AI-Based Smart Attendance System is a real-time attendance platform built to automate student check-ins using face recognition and a live ESP32-CAM feed. The project combines computer vision with a lightweight web dashboard to make attendance faster, more reliable, and easier to review.

## Key Features

- **Face recognition attendance** for automated identity matching.
- **Live camera feed** powered by ESP32-CAM for continuous capture.
- **Present and late marking** based on attendance timing logic.
- **Excel report generation** for practical record export.
- **Real-time dashboard** for monitoring attendance status as data updates.

## Tech Stack

- **Python** for the main application logic.
- **Flask** for the backend and dashboard integration.
- **OpenCV** for image processing and face recognition workflows.
- **ESP32-CAM** for live image capture.
- **Pandas** for attendance processing and Excel exports.
- **JavaScript** for interactive dashboard behavior.

## Build Focus

The main focus of this project was reliability in real classroom usage. I worked on handling the live stream, matching recognized faces against student records, and transforming captured events into useful attendance logs that could be reviewed instantly or exported later.

## Outcome

This project demonstrates my interest in combining hardware, backend systems, and applied AI to solve practical problems. It also strengthened my skills in integrating real-time input, data processing, and usable admin workflows.
