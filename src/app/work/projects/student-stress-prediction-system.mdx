## Overview

Student Stress Prediction System is a machine learning project designed to estimate stress levels from academic and lifestyle signals. The goal was to build a model pipeline that could compare multiple algorithms, identify useful patterns, and present findings clearly.

## Key Features

- **Logistic Regression** baseline for interpretable classification.
- **Random Forest** for stronger nonlinear modeling.
- **PCA** for dimensionality reduction and feature analysis.
- **XGBoost** for high-performing predictive modeling.
- **85% accuracy** achieved during evaluation.

## Tech Stack

- **Python** for model development and experimentation.
- **Scikit-learn** for preprocessing, model training, and evaluation.
- **XGBoost** for boosted ensemble prediction.
- **Pandas** and **NumPy** for dataset preparation.
- **Matplotlib** for visual analysis.

## Build Focus

I focused on preparing the dataset carefully, comparing algorithms fairly, and understanding which combinations of features contributed most to the final prediction quality. The project helped me build stronger intuition around preprocessing, evaluation, and model comparison.

## Outcome

This system reflects my growing interest in machine learning applied to real-world educational problems. It gave me hands-on experience with end-to-end model experimentation, accuracy tracking, and communicating results in a practical format.
